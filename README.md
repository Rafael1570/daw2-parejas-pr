# Jornadas de Informática DAW

Web de unas jornadas de informática, desarrollada en pareja
para practicar GitHub Flow y la revisión mediante Pull Requests.

## Páginas

- index.html: presentación de las jornadas.
- programa.html: horarios y actividades.
- inscripcion.html: formulario de inscripción de demostración.
- css/styles.css: estilos compartidos y diseño adaptable.

## Tecnologías

HTML5, CSS3, Git y GitHub.

## Trabajo en equipo

Cada tarea se desarrolla en una rama feature/.
Los cambios se proponen mediante Pull Requests hacia main,
con al menos una aprobación del otro miembro.

## Comprobación local

Abrir el proyecto en VS Code y ejecutar index.html con Live Server.
Para comprobar todas las páginas, sus Pull Requests deben estar
integradas en main.
